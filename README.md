# Sanguivar

Sanguivar is a fantasy text-based RPG that I started while learning Python and developing my programming skills.

The project begins as a simple text adventure and will grow over time as i learn new programming concepts. 

## 🎮 Current Features

-Player name creation
-Three playable character classes: Warrior, Witch and Healer
-Different health, strength and magic stats for each class
-Class-specific starting equipment
-Inventory system
-Player choices and exploration 
-Item collection 
-Basic story progression

## ⚔️ Character Classes

###Warrior
-Health: 5
-Strength: 6
-Magic: 4
-Starting item: Sword

### Witch 
-Health: 5
-Strength: 4
-Magic: 6
-Starting item: Wand

### Healer
-Health: 5
-Strength: 5
-Magic: 5
-Starting item: Alchemy kit


## 🗺️ Long-Term Goal

My long-term goal is to develop Sanguivar into a playable 2D fantasy RPG, gradually adding more features and systems as my programming skills develop.
