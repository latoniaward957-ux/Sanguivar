# Sanguivar

Sanguivar is a fantasy text-based RPG that I started while learning Python and developing my programming skills.

The project begins as a simple text adventure and will grow over time as i learn new programming concepts. 

## 🎮 Current Features

-Character name creation
-Player choices
-Inventory system
-Early exploration

## 🗺️ Long-Term Goal

My long-term goal is to develop Sanguivar into a playable 2D fantasy RPG, gradually adding more features and systems as my programming skills develop.

## 🛠️ Built With

Python

## 🚧 Project Status

**Early development** - currently a text-based prototype

This repository will document Sanguivar's development from my first Python version onwards.
